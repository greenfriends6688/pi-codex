# Pinkslab v0.1.5-beta.3

这一版是**照着 Zeno 的外观壳子重做了一遍界面**，外加三处用户直接指定的布局调整。
全部零新依赖（不引图标库、不引组件库、不引拖拽库）。

## 新增

- **主题皮肤**：一套皮肤 = 4 个基色 + 11 个几何/材质旋钮 + 一张壁纸 + 一段自定义 CSS，
  **11 个滑块全部真的落到 CSS 变量上**，不是只有 UI 没有效果。
  - 卡片条：横向滚动的迷你外壳缩略图（壁纸 + 玻璃块 + 强调色条），左右滚动按钮，
    底部 `新建主题 / 导入 / 编辑 / 导出`；导入自动换 id，导出成 JSON。
  - 编辑主题对话框：`主题设置 / 自定义 CSS` 两页，左侧界面预览（浅色/深色切换 +
    真·迷你外壳 + 选择壁纸 + 填充方式），右侧 4 个色值 + 11 个双列滑块，
    底部 `取消 / 恢复默认 / 保存`。
  - 皮肤只存 4 个基色，其余槽位（hover / 选中 / 次要文字 / 三档边框）在应用时用
    `color-mix` 现场派生 —— 改一个基色整套跟着变，导出给别人时也不会出现十几个
    用户从没见过的色值。
  - **壁纸与主题融合**：壁纸铺满全窗，侧栏/会话列/顶栏/作曲器各自半透明 + 模糊，
    会话列再叠一层方向性阅读遮罩（正文一侧最实、主体一侧最透）。

- **设置页新增四项**（照 Zeno 的设置行形状：标签与说明在左、控件在右上、行间内缩分隔线）
  - **UI 字体**：真枚举本机字体（先试 Local Font Access API，拿不到再用 canvas 探测
    29 个候选族名），不是只有「系统默认 / 衬线 / 等宽」三档。
  - **UI 字号**、**侧边栏半透明**（`backdrop-filter`）、**侧边栏宽度**（直驱拖拽面板）。

- **通知设置**：开关矩阵（桌面通知 / 任务完成 / 任务失败 / 仅在窗口未聚焦时 /
  通知声音）+ `发送测试通知` / `打开系统通知设置`。开关**真接进三条投递路径**，
  失败通知新增了 `onAgentError` 回调（从 `useAgentSession` 的两个 error 站点穿出）。

- **小地图悬停提示**：悬停会话轨道上的某一根 dash，显示这一回合的角色与正文预览。

## 改动

- **侧栏**：
  - 行规格照 Zeno：hover 与选中**同填充**、选中不加字重、计数徽标 11px 右对齐。
  - 内缩统一成 10px（此前是 0 / 6 / 10 三种，行填充对不齐）。
  - 宽度默认 272 → **300**，拖拽区间 216–520 → **232–360**（原来抄的是 Zeno 的遗留
    兜底 token，不是它实际在跑的值）。
  - 分区顺序改成 **项目 → 聊天**；新增「项目 / 聊天」左右分段切换，互斥渲染。
  - **折叠按钮从导轨右边界移进品牌行**（原来一半压在主区顶栏上，和顶栏那排图标抢
    同一条线）；**折叠态改成三个图标的紧凑条**（展开 / 搜索 / 新建会话），
    不再是一个孤零零的按钮。
  - 去掉「插件 / 技能」两行 —— 设置里已经有这两个分区，导轨上再来一份是重复入口。

## 修复

- **开着壁纸时侧栏与副区整块全透明**：`app/wallpaper.css` 把
  `max(35%, calc(var(--wallpaper-scrim) - 5%))` 当 `color-mix()` 的百分比用，
  Chrome 不接受数学函数放在那个位置，整条 `background` 在 computed-value 阶段失效、
  回落成 `transparent`。这个 bug 被「透过去看到壁纸」的表象盖住了很久，
  直到皮肤把壁纸铺满全窗才暴露。改成在 JS 里算成纯百分比写出去。
